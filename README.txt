# مساعد المزرعة — Farm Advisor

## محتويات المشروع
- `index.html`: واجهة التطبيق المتجاوبة.
- `core.js`: طبقة الدعم التي تُكمل المتغيرات والدوال التي يعتمد عليها `farm.js`.
- `farm.js`: الملف الأصلي المرفق لإدارة قطع المزرعة والتشخيص الإرشادي والكومبوست.
- `manifest.json` و`sw.js` و`icon.svg`: ملفات تثبيت PWA والعمل دون اتصال بعد أول تحميل.

## طريقة التثبيت على Android
1. ارفع محتويات هذا المجلد إلى استضافة HTTPS مثل Netlify أو GitHub Pages.
2. افتح رابط التطبيق في Chrome على الهاتف.
3. من قائمة Chrome اختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق**.
4. بعد التحميل الأول، يمكن فتح الواجهة الأساسية دون اتصال. ميزات الطقس المباشر غير موصولة بخدمة طقس في هذه النسخة.

## ملاحظات مهمة
- هذه نسخة ويب قابلة للتثبيت (PWA)، وليست ملف APK أصليًا.
- حفظ بيانات المزرعة في `farm.js` يتم محليًا في `localStorage` على الجهاز والمتصفح نفسه.
- التشخيص الزراعي تقريبي قائم على الأعراض والألوان، وليس نموذج ذكاء اصطناعي لتحديد الأمراض من الصور.
- تقديرات الري والكومبوست تقريبية. لا تعتمد عليها وحدها لاتخاذ قرارات زراعية أو استخدام مبيدات.
- لم تُربط خدمة طقس خارجية، ولا يوجد حساب سحابي.
